The equations

Two lines of calculus, 138,639 times.

// every neuron, every 0.1 ms dv/dt = (v₀ − v + g) / τm τm = 20 ms dg/dt = −g / τs τs = 5 ms if v > −45 mV: spike v ← −52 mV, g ← 0, rest 2.2 ms each target: g += synapses × 0.275 mV after 1.8 ms

The brain model follows Shiu et al. (2024, Nature), where the same equations on the same wiring predicted which neurons drive feeding and grooming, and experiments confirmed it.

FlyLeno integrates the model lazily. Between inputs a neuron's voltage has a closed form, so a cell is only stepped while it could reach threshold. That keeps 15 million connections running in plain JavaScript in a Web Worker.

On top of the connectome sits a small learning loop. The fly's own PAM and PPL1 dopamine neurons, driven by the crowd, gate plasticity on the synapses onto Leno's vocal motor neurons. Jokes that get applause get repeated.
